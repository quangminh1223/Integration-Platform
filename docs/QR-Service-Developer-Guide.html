1. Tổng quan kiến trúc

QR Service là một microservice xử lý các nghiệp vụ liên quan đến mã QR, chuyển đổi bản tin ISO8583, và cung cấp khả năng tích hợp API động thông qua import file Swagger.

Các thành phần chính

Thành phầnMô tảPackage
RestClientServiceGọi REST API backend động theo methodservice
FlexibleBody / HttpInputResolverNhận body JSON ở mọi dạng inputcommon/http
Iso8583ServiceParse/Build bản tin ISO8583 dùng jPOSservice
SwaggerImportServiceImport Swagger 2.0/OpenAPI 3.x, đăng ký route độngswagger/service
DynamicRouteRegistryLưu trữ route động trong memory (thread-safe)swagger/registry
VietQrBuilderServiceBuild/Parse chuỗi VietQR chuẩn NAPASservice
